# 页面流程、家庭干预与机构课程

日期：2026-10-19。根据用户逐页反馈讨论后确认的方案。本轮修改在云端开发，生产发布需另行安排；不能将本机验收写成线上已经更新。

## 页面与保存流程

- **今天**：展示当天家庭干预、机构课程及到期复盘。家人给予的支持称为家庭干预；机构老师的上课记录单独维护。较早的记录从记录页查看。
- **记录**：顶部切换“机构课程 / 家庭干预”，默认机构课程；两种列表分开。机构课程显示老师课时统计，家庭干预显示已保存计划和完成总结。
- **目标**：名称必填，领域分类可选，可从已有分类选择或自行填写。中短期目标允许暂不关联上级；选择时中期只关联长期、短期只关联中期。保存错误在表单中显示，不关闭表单或丢弃输入。新建使用稳定 ID，收到响应前重试相同内容不会重复创建。
- **方法**：UI 将“途径”统一为“方法”，关联目标放在名称和步骤之前，可从目标和方法详情相互跳转。目标与方法仍为多对多。归档保留关系与历史。
- **跟进**：困难和经验分别维护，使用“关联目标 / 关联方法”；经验录入与展示统一称“验证依据”，困难称“跟进结论”。目标详情显示直接关联的经验，以及关联方法下的经验，注明绑定类型。
- **规划**：取消独立导航。制定计划时先显示近 30 天未覆盖的短期目标提示，按需展开原有环形图与统计；点击未覆盖筛选会直接显示目标列表并收起图表，可加入当前计划。

家庭干预流程：

1. 安排计划，选择一个主目标；副目标可选，复习目标另选。可以直接更换目标；选择计划中已有的另一个目标时交换角色，计划和观察仍归原目标所有。
2. “保存计划并退出”将同一记录保存为服务器草稿，其他家人刷新后可见。
3. 今天的安排显示“填写干预总结”；较早日期的待总结计划从记录页的家庭干预查看。
4. 总结可“保存总结草稿并退出”，正式提交后才完成，并在同一事务中生成困难和经验。
5. 困难、经验默认关联主目标；下拉可更改目标或关联方法，计划内目标优先。选择仅关联方法时，不自动追加目标绑定。困难与经验会出现在相应目标、方法和跟进页。

未正式提交的输入仍自动保存到本机，按账号和空间隔离；服务器草稿与本机草稿须区别显示。未确认提交结果时保留相同 operation_id 重试。旧的已完成训练及导入记录不自动推断目标或方法关联；需要时人工补充跟进绑定。

## 日期与复盘提醒

日期字段提供浏览器日期选择器和 YYYY-MM-DD 数字输入。进入目标复盘时，本次日期默认当天，下次默认当天后两周，均可手动修改。日期以应用现有的 Asia/Shanghai 业务日为准。

到期及逾期目标在打开今天页、返回网页或可见页面刷新后弹出提醒；正在填写的表单不会因此被替换。用户可以进入目标复盘，或选择当天不再弹出、稍后在待复盘列表查看。次日仍未处理的到期目标再次提醒。此功能是网页内提醒，关闭网页后不发送系统推送。

## 课程、老师与课时

- 课程和老师独立维护，同一老师可以教不同课程；下拉显示已有可用选项，可新增并保存到共享服务器。
- 记录页提供停用／恢复选项。停用不删除或改写历史课程，历史统计保持原样，编辑原记录仍能显示其旧值。
- 默认统计上一个自然月，起止日期均包含，可手动调整或恢复默认范围；按老师汇总，每条上课记录计一节。不处理半节、取消课和时长折算。
- 保存上课记录后退出表单并回到页面顶部。遇到另一位家人修改同一条记录，保留本机草稿，显示最新内容并提供备份后载入最新版本的操作。

## 多浏览者与持久数据

后续T30已加入管理员删除及全体登录成员的已完成训练修订，删除关联规则、历史、冲突与验收见[权限与修订](record-permissions.md)。本页其余流程继续适用，不能把本地完成当作生产已更新。

可见网页每 20 秒刷新共享数据，回到窗口或恢复可见时也刷新；请求失败显示同步状态，保留编辑内容。晚返回的旧读取结果不会覆盖已确认的较新版本。目标、方法、跟进、课程和干预都保持版本校验；自动刷新不替换正在编辑的表单或悄悄提升其基础版本，冲突需人工核对。

沿用原生 SQLite 和 Cloudflare SQLite DO 两种存储。迁移 `008_lesson_options.sql` 追加共享课程／老师选项表，从历史课程提取已有名称，重复启动不会重建记录。目标、方法和跟进绑定继续使用原表及 JSON；新增字段有默认值，并在为空时省略序列化，兼容旧记录和未确认请求的指纹。旧库升级至 008 后，旧版本程序会因版本较高而拒绝启动，回退需选择兼容构建，不能删库处理。

正式发布时应保留 `skarma-web`、`SkarmaSpace`、`SKARMA_DB`、`SKARMA_SPACE=default`、skarma.vip Custom Domain 及精确允许来源；先完成数据库备份和兼容性核对。本轮未读取或修改生产数据、未重做腾讯工作簿导入。

Excel 继续提供十一张工作表，新增困难／经验及训练草稿的目标和方法关联 ID 列。为保留现有导出脚本兼容性，历史工作表名“途径”“目的途径关系”和相应 ID 列暂不改名；界面使用新称呼。Excel 不包含账号和会话，仍不是整库备份。

## 验证入口

- `cargo test --workspace --locked`：含独立目标、单主目标完成、默认及显式跟进绑定、关系写入失败回滚、选项版本冲突、迁移保留及既有认证／导入。
- `npm run typecheck`、`npm run web:build`。
- `node --test tools/test-workflow.mjs tools/test-planning.mjs`：自然月边界、老师计数、角色交换、旧响应合并和候选排序。
- `npm run test:runtimes`：原生 SQLite 与真实 Rust Wasm / Miniflare DO 的共用合约，含新选项、跟进绑定、重启保留及 Excel。
- `npm run test:host`：手机浏览器录入、规划筛选、离线草稿、丢响应重试、日期提醒、两个登录会话的刷新和冲突、课程统计及备份恢复。

以上均使用临时合成数据，真实大陆手机网络和新版本线上验收应在正式发布后另记。
