# 管理员删除与训练修订

日期：2026-10-20（Asia/Singapore）。用户确认删除只开放给管理员、训练修改开放给所有人；这里的所有人指已登录且有效的家人成员。仅在开发环境实现和验收，尚未部署。

## 权限与入口

| 操作 | 管理员 | 普通成员 |
| --- | --- | --- |
| 新建及编辑目标、方法、困难／经验、课程 | 可以 | 可以 |
| 编辑家庭干预计划及总结草稿 | 可以 | 可以 |
| 修改已完成训练并查看版本历史 | 可以 | 可以 |
| 删除目标、方法、困难、经验、训练及上课记录 | 可以，需二次确认 | 不显示入口；直接请求也返回403 |

删除权限在共享后端事务内重新检查有效会话和角色，原生SQLite及Cloudflare DO采用同一规则；示例免登录模式不提供删除。删除请求带确认时的版本，别人已修改时返回409，需刷新核对，不能直接删掉新版本。

目标详情、方法详情、跟进卡片、训练草稿／详情和上课记录编辑页提供相应删除按钮。页面不提供撤销，确认前说明关联处理方式。

## 删除如何处理关联

- **目标**：有下级目标或仍被任何训练（包括草稿）引用时拒绝删除，并提示先处理关联，或使用归档。可删除时保留方法、困难和经验，只解除它们对此目标的绑定。
- **方法**：保留目标、经验、困难和训练，解除所有对此方法的实时绑定；受影响记录版本递增，训练保留其关联变化前后的版本。
- **训练**：删除本次计划／总结，保留已有困难和经验；这些跟进标注“原来源训练已删除”，不再显示失效的来源按钮。不撤销训练以前引起的目标归档。
- **困难／经验**：移除跟进记录及其关联，原训练总结保留当时填写的内容。后续修订原训练不会自动恢复管理员已删除的跟进。
- **上课记录**：从列表和老师课时统计移除该记录，课程／老师选项继续保留。

删除与关联清理是同一事务；任何一步失败均回滚。数据库保留删除标记及私有审计快照，阻止旧ID或迟到的草稿／重试请求重建已删除记录；这不是页面回收站。公开状态仅返回删除类型与ID，审计快照不通过网页或Excel导出。

其他设备在自动刷新、回到网页或手动刷新后移除记录；旧读取结果不能使它重新出现在列表。正在填写的训练／上课本机草稿显示记录已删除，禁止保存到原ID，提供“备份填写并关闭已删除草稿”后继续新建。

## 修改已完成训练

从“记录 → 家庭干预”或当天已完成记录进入训练回看，点击“修改训练”。可以修改计划、日期、目标及观察，填写本次修订说明后点击“保存训练修改”；修改中的内容保留为本机草稿，正式保存后仍是同一条已完成训练，不降为待完成、不重复计数。

暂时返回会保留本机修订草稿，可从记录页继续。若不再提交，可“备份填写并取消修改”，备份当前本机内容并返回已保存版本，不产生新训练版本。

每次修订版本递增，保留修订前后完整训练数据及说明；详情下方显示版本历史。原有目标沿用训练当时的快照，新加入的目标使用当前定义。修订不重复归档目标，也不自动撤销后来已有的目标状态。导入的历史记录原本缺少活动、组织方式或主辅目标时，可以继续修订而不补造这些信息；首次完成的新训练仍执行原有必填校验。

训练与跟进的更新规则：

1. 只修改观察等无关字段，不改写已在跟进页整理过的困难／经验。
2. 实际修改困难／待验证经验内容、类型或绑定时，同步对应字段，保留原跟进ID、来源、状态和依据；未改动的绑定不会覆盖在跟进页单独调整的关系。已验证或停用经验独立维护，不被来源训练修订覆盖；更正它们需在跟进页单独操作，训练原始总结仍可修正。
3. 同步前核对打开修订时的跟进版本；期间其他人改过则整次修订返回冲突，训练、跟进、版本历史都不部分保存。
4. 取消总结中的困难／经验标记不删除已有跟进；删除仍需管理员操作。
5. 相同提交标识重试不会重复生成训练、历史或跟进；两个家人同时改同一训练时只有一个成功，另一个保留本机输入并提示核对最新版本。

## 数据与部署

迁移`009_record_changes.sql`只追加删除审计和训练修订表，不替换现有业务表、管理员、来源导入行或空间。版本高于旧程序支持范围时拒绝旧程序启动，不能删迁移记录强行降级。训练修订历史及删除审计保存在数据库备份中，Excel继续导出十一张表及当前业务记录，不作为整库备份。

发布前仍需受控备份，保留原Worker、DO绑定、default空间、skarma.vip和精确来源。本轮没有访问账号数据、重做导入或部署。
