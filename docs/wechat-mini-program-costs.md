# 微信小程序与现有部署路线的成本对比

调研日期：2026-10-19，Asia/Singapore。按约 3–5 位家人、iPhone / Android 混用、
主要在中国大陆访问、以文字训练及课程记录为主估算；人数与用量是预算假设，非实测。
本轮仅补充研究和交接文件，未改应用、开通资源、登录生产账号或部署；生产发布继续暂停。

## 判断

微信小程序值得列为低维护成本候选。小额托管费可能比自建同步协议和维护两端原生分发更划算，
但当前 RN / Expo 应用不能直接上传成为小程序，改造费用不能忽略。
现有常开家庭电脑仍是有效候选：可持久接收变更并向稍后上线的手机补传，手机不必同时在线。
它省去新增服务器租金，未消除跨网连接、同步实现、备份恢复和客户端分发的工作。

本次不改变架构选择，不将研究标为实现。家庭节点研究见
[libp2p 方案](libp2p-family-sync-proposal.md)，现有云端访问问题见
[大陆访问计划](mainland-access-plan.md)。

5 位家人共用一个业务环境时按环境及资源计费，不把月费简单乘以人数；实际读写和流量仍随使用增长。

## 已核实的价格与产品边界

1. [CloudBase 定价](https://cloudbase.net/pricing)：免费体验版每月 3,000 资源点；
   个人版现价 19.9 元/月、40,000 点；标准版 199 元/月。数据库、函数、存储和流量等共享点池。
   免费版页面描述单次续期 6 个月，付费版可加购资源或超限按量；不能据此推断所有已发布
   微信小程序环境都可持续免费。
2. [资源点 FAQ](https://docs.cloudbase.net/quick-start/resource-point)：确认资源统一扣点、
   套餐 → 资源包 → 按量的顺序，并区分旧套餐和可切换环境。40,000 点不是无限调用，
   本项目尚未做用量测试，不保证最低套餐一定覆盖。不要把当前全量读取 `/api/state` 的模式
   原样替换成频繁直读云数据库，再按「只有几个人」推断不会超额。
3. [云托管计费](https://docs.cloudbase.net/run/faq/fee)：**微信云托管**根据启动实例的
   CPU / 内存按量计量、每日结算；**云开发中的云托管**换算为环境计算资源，按套餐、资源包、
   按量扣除。这是不同计费入口，不能混为同一个 19.9 元套餐，也不能未经核对承诺空闲零费用。
4. [小程序调用容器](https://docs.cloudbase.net/run/develop/access/mini)：关联相应环境后
   可用 `wx.cloud.callContainer`，无需在小程序后台配置服务器域名；某些用户信息能力仅适用于
   微信云托管。免自购业务域名依赖正确的内置调用路径，不等于任何免费 HTTP 地址都可生产使用。
5. [容器迁移说明](https://docs.cloudbase.net/run/best-practice/migration)：服务按无状态设计，
   节点可能销毁重建，正式数据不能只保存在容器本地 SQLite 文件。
6. [Apple 会员权益与费用](https://developer.apple.com/programs/whats-included/)：标准会员
   99 美元/会员年或可用的当地币种价。此费用针对所选原生分发路线；继续用 Web 或改用微信
   小程序不需要为该客户端购买 Apple 开发者会员。短期测试分发不能直接当作长期免维护分发。

## 改造成本与建议

- **小程序 + 云开发内置调用**：家人进入方便，不维护独立 iOS / Android 安装包，后端资源由平台
  运维。页面与平台 API 需要适配；微信身份还需映射家庭成员与审批权限，不能直接照搬当前网页
  Cookie 登录。若改用云函数 / 云数据库，不能假定现有 Rust HTTP / SQLite 后端完全不改。
- **小程序 + Rust 容器**：复用 Rust 领域逻辑，但数据库持久化、账号衔接、Excel 文件下载以及
  既有数据迁移仍需设计。若保留 Web / 原生 App 并增加小程序，会多维护一个客户端入口。
- **家庭节点 + 原生 App**：适合重视离线能力、数据副本控制和复用常开电脑的目标；开发面更大。
  libp2p 提供通信，不直接提供幂等变更日志、冲突处理、断网补传或换机恢复。
  现有主机连接未恢复，未来原型可以用云端进程 / 容器模拟持久节点，不能视为真实网络已通过。

若能接受每月一小笔托管费，建议将小程序作为优先验证候选，先确认实际可购套餐与认证成本，
再比较「复用 Rust 容器」和「改云函数」的总工作量。它可能比原生双端 + 自建同步省总成本，
不能只凭 19.9 元促销断言更便宜。若必须维持原生离线体验与家庭节点方向，继续该路线，
将分发、网络可达性和维护工时明确计入预算。本轮未启动任何一种实现。
