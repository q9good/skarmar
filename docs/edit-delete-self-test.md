| 操作 | 数据与页面结果 |
| --- | --- |
| 编辑目标名称、标准及复盘记录 | 保存成功、版本递增；新旧版本均在修改历史中；既有训练目标快照不被改写 |
| 编辑方法名称、步骤并改绑目标 | 同一ID更新；旧目标不再显示该方法，新目标显示该方法及其经验；经验原有的直接目标绑定不被自动改写 |
| 编辑独立经验 | 修改内容、验证依据和状态，换目标并解除方法绑定；旧目标及方法中不再显示，新目标显示；仍无虚构来源训练 |
| 编辑训练生成的经验 | 修改内容、依据和目标绑定；保留原方法与来源训练ID，来源跳转正确；历史训练总结保留当时填写内容 |
| 解除／恢复方法的全部目标关联 | 目标页相应更新；方法及直接绑定它的经验保持原ID，不随解绑删除 |
| 编辑已保存训练计划 | 同一草稿ID更新安排、直接更换主目标，旧目标中移除、新目标中出现；未重复创建训练 |
| 移除／重新添加草稿主目标 | 保存后关联索引和目标页随之更新；未误删目标本身 |
| 编辑并保存训练总结草稿 | 观察和逐目标进度可再打开继续编辑；仍是草稿，未提前生成重复经验 |
| 目标、方法归档后恢复 | 原记录及关系保留，恢复活动状态成功；既有已完成训练内容不变 |
| 经验停用后恢复已验证 | 内容、绑定与依据保留，恢复成功 |
| 刷新及另一个独立登录会话 | 显示编辑后的方法、经验、目标关联及训练草稿 |
| 两个后端停止并重启 | 重启前后的完整AppState逐项一致 |

对保存结果另行检查字段、恢复后的状态及记录数量，两套后端均一致。浏览器未报告运行时错误，手机尺寸页面无横向溢出。

## 已确认缺失，不能算通过的功能

**记录删除尚未实现。** 页面无删除按钮，HTTP路由也未提供DELETE处理。
本轮对目标、方法、经验、已完成训练及草稿训练共5类情形发送经过登录和来源检查的删除请求，两套后端均返回HTTP 405，完整业务状态未变化。
这只证明当前不能删除，不代表已验证删除后的关系清理、级联或恢复；归档、停用、解除关联均不能替代删除。

**已完成训练尚不能修订。** 页面只有回看入口；对正确版本的已完成训练提交修改，两个后端均返回HTTP 409及“已完成记录暂只支持回看；修订功能将单独提供”，完整业务状态未变化。
因此“训练编辑通过”仅适用于草稿计划与总结，不包括已完成记录。后续修改跟进经验，也不会回写原训练总结。

本轮未新增这两项能力，未部署。训练直接选择实际使用方法及次数仍属T10，亦未由本次验收完成。
