# 目的、途径与经验

日期：2026-10-17。已按本次反馈接入领域模型、API、手机 Web 与 Excel。

## 三类对象与关系

| 对象 | 负责什么 | 例子 |
| --- | --- | --- |
| 目的（沿用现有 Goal／目标） | 想达到什么，保留长期／中期／短期层级及达成标准 | 主动表达需要、逐步独立完成生活任务 |
| 途径（Pathway） | 实现目的的方式，包含作用说明与具体步骤，可被多个目的复用 | 视觉提示、共同阅读、分步练习 |
| 经验（Experience） | 对原则或具体操作的认识，记录适用对象、来源与验证依据 | 回应沟通意图；某个提示步骤的具体做法 |

```mermaid
flowchart LR
    G["目的：长期／中期／短期"] <-->|多对多| P["途径：说明与步骤"]
    E["经验：正文、来源、验证"] <-->|宏观原则 · 多对多| G
    E <-->|微观细节 · 多对多| P
```

目的层级与途径映射分别保存。一个目的可有多种途径，一个途径也可以服务多个目的。
一条经验可关联多个目的、多个途径，也可以同时关联两者。每个目的和途径都可以积累多条经验。

例如，视觉提示可以同时用于“表达需要”和“独立完成生活任务”；“先理解需要，再选择支持方式”可关联目的，“一次展示两张图片”的操作记录可关联视觉提示。正文继续填写适用条件与观察依据，绑定关系本身不代表已经验证有效。

## 来源与适用范围

- 从训练生成的经验继续保留来源训练；完成训练后仍先进入待验证状态。
- 独立整理的经验／原则允许没有来源训练，至少明确一个适用目的或途径，不生成虚构训练。
- 来源说明经验从哪里来；绑定说明它准备应用到哪里，两者分别保存。
- 经验只绑定途径时，途径服务的目的不会自动写入经验的目的绑定。目的详情可沿途径查看细节，界面区分“目的原则”和“途径细节”。
- 原来的“长期普适／中短期任务”标签继续保留。旧经验先保持未绑定状态，由使用者补充确认；不依赖标签或来源训练猜测适用范围。

## 保存与兼容

新增共享 SQL 迁移 `004_pathways.sql`，本地 SQLite 与 Cloudflare SQLite Durable Object 使用相同模型与规则。

| 表 | 责任 |
| --- | --- |
| `pathways` | 稳定 ID、名称、说明、步骤、活动／归档状态和版本 |
| `goal_pathways` | 目的与途径的多对多关系 |
| `experience_goals` | 经验与目的的多对多关系 |
| `experience_pathways` | 经验与途径的多对多关系 |

关联表使用复合主键和两侧外键。正文、版本和关联关系在同一个事务中保存，任一写入失败全部回滚。接口拒绝重复 ID 和不存在的关联对象。更新途径或经验都检查基础版本，界面遇到冲突保留填写内容，用户核对后再选择如何继续。

归档保留实体和关系。更改途径服务的目的，不自动改写已经明确绑定的经验。旧客户端更新经验时省略 `goal_ids`／`pathway_ids` 会保留关系，明确传 `[]` 才清除相应关联。迁移保留旧正文、来源、分类和训练快照。

## 页面与接口

- **目标**：继续维护目的层级；详情增加关联途径和经验。
- **途径**：新建／编辑名称、作用与步骤，多选适用目的，归档后仍可查看。
- **跟进**：增加独立经验入口；已有训练经验可补充目的／途径绑定并编辑整理后的正文。来源训练继续保留原内容。
- **我的账号 → 导出 Excel**：增加“途径”“目的途径关系”“经验关联”，共十张工作表。

新增接口 `POST /api/pathways`、`PUT /api/pathways/{id}`、`POST /api/experiences`。现有 `PUT /api/experiences/{id}` 增加可选正文与两类关联 ID；所有接口沿用共享空间登录保护。

本轮落实途径目录、目的映射和经验适用范围。训练原有逐目标安排／观察继续保留；下一步接入训练途径时，应以训练明细关联实际使用的途径和版本快照，分别记录“可用方式”和“这次实际怎样做”。当前目录关系不作为某次训练已使用该途径的证据。

## 验证

Rust 验收覆盖双向外键、多对多复用、独立经验三种绑定、关联事务回滚、旧客户端保留绑定、版本冲突、归档与来源／训练快照保留，以及旧库不推断关系。相同 HTTP 合约还验证本地 SQLite 和真实 Rust Wasm／DO 模拟器，包含 SQL 写入中途失败。

手机尺寸浏览器验证目的／途径多选、独立原则与细节、目的详情呈现、两类编辑冲突时保留输入、途径归档及 Excel 关系完整性。真实设备与公网主机验收仍在部署阶段完成。
