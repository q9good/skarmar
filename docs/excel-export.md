# Excel 导出

登录后打开 **我的账号 → 导出 Excel**。管理员与成员均可下载当前共享空间中已保存的全部数据；手机浏览器在下载列表中保存 `.xlsx` 文件，可用 Excel / WPS 打开。

| 工作表 | 内容 |
| --- | --- |
| 说明 | UTC 导出时间、范围、关联方式和记录数量 |
| 目标 | 当前长期／中期／短期目标、上级 ID、标准、状态、版本和复盘日期 |
| 训练记录 | 已保存草稿与完成记录、活动、整体安排与观察、困难和经验正文 |
| 逐目标明细 | 训练关联、主／副／复习角色、安排、实际进度、处理结果，以及当时保存的完整目标快照 |
| 困难 | 来源训练、跟进状态、下次日期和结论 |
| 经验 | 来源训练、经验类型、验证状态和依据 |
| 目标历史 | 每个目标的全部已记录版本、UTC 时间、修改说明和来源训练 |
| 途径 | 实现方式、具体步骤、状态与版本 |
| 目的途径关系 | 当前目的与途径的全部显式多对多关联 |
| 经验关联 | 经验分别绑定的目的与途径；每个显式关联一行 |

十张工作表用目标 ID、上级目标 ID、途径 ID、经验 ID、训练 ID、来源训练 ID 关联。独立经验没有来源训练时留空。已完成训练保留当时目标名称与标准，当前目标修改后导出仍可对照历史版本。缺少旧快照时留空并标记“缺失，需核对”，不借用当前目标补写历史。

中文列名、冻结首行和筛选已配置；文字自动换行。日期、版本、ID 与正文按文本保存，空白表示未填写／未知。活动列表在单元格中以换行分隔。正文以 `=`、`+`、`-` 或 `@` 开头时仍是文字，不执行为公式。

导出读取同一事务中的已保存快照，不修改业务数据。浏览器里尚未保存的草稿、账号密码哈希、会话令牌和登录记录均不包含在文件中。会话失效时返回登录页，重新登录后可再次导出。

Excel 用于查阅、筛选和归档；当前尚无 Excel 导入。需要恢复整个系统时使用 [数据库备份／恢复](host-deployment.md#备份与恢复)。首版为全量导出，暂不提供日期筛选或分批导出；超过 Excel 单表行数或单元格长度时明确报错，不截断内容。

## 实现与验证

接口为 `GET /api/export.xlsx`，要求有效登录，响应为 OOXML MIME、附件下载与 `Cache-Control: no-store`。明确的本机合成数据 demo 仍沿用示例认证。

共享 Rust 写入器采用 `rust_xlsxwriter` 0.99.1，在内存中生成真实 XLSX。原生 SQLite 在事务内完成身份校验与快照读取，再释放数据库锁，用阻塞任务线程生成文件。Cloudflare 在 SQLite Durable Object 内读取快照、提交事务后生成二进制文件，普通 Worker 入口负责转发。无需新增储存服务或文件目录。

`npm run test:runtimes` 在本地 SQLite 和真实 Rust Wasm / DO 模拟器上验证内容、历史版本、中文／emoji／换行、正文公式字符、全部关系和数量、成员下载及未登录／停用／过期拒绝。`npm run test:host` 用 390 × 844 的 Chromium 页面实际下载文件，验证未保存草稿排除、异常网关页面拒绝下载及过期回到登录。文件由独立 Python ZIP/XML 读取器核对，无须安装 Excel 解析包。

本机模拟验收不能替代真实 iOS／Android 浏览器、用户主机或 Cloudflare 生产 CPU／内存额度验收；原生 App 文件分享将在二期接入。
