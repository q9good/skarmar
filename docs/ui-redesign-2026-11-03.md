# skarmar：主题色、操作层级与家庭计划重排

配色已按后续用户反馈调整为[Nord衍生方案](ui-palette-research-2026-11-03.md)；本页保留T65当时的设计与13图证据。

采用 Garden `web-design-engineer` 的既有产品重设计方法，基于当前RN／Expo源码与已有合成截图。
用户已明确授权设计和实现，家庭计划内容与顺序按本次要求执行；颜色选择先按功能固定配色推进。

## 设计决策

- 模式：Redesign · Preserve。保留skarmar字标、五个主导航、业务内容、关联语义、返回行为和所有正式数据。
- 面向父母及老人使用的手机工具，强调一屏内的填写主线和明确按钮，不做展示型动效。
- 五项取向：视觉变化3／动效1／密度5／图像依赖1／品牌保留8。使用真实现有图标与字标，不添加装饰图片。
- 功能主题：家庭陶土棕 `#8B4B32`、课堂蓝 `#225E82`、目标松绿 `#25624F`、方法靛蓝 `#4C528A`、经验绿 `#2C684B`、困难赭金 `#7E591B`。一屏以当前功能色为主，知识提示保留绿／金语义。
- 背景为近白暖色，正文深墨绿、白色内容面和细边框；主按钮实色白字，次按钮白底描边，轻操作为文字链接。
- 字体沿用本机中文无衬线及已有大字模式，正文16–18px、分区18–20px、页面标题26px；颜色不承担唯一提示。
- 间距基于4／8px：控件12px、区块16–20px、组间20px。按钮12px圆角、内容16px、只在主操作与浮层使用轻阴影。
- 触摸区域至少44px，大字模式继续56px；键盘焦点明确。按压仅轻微反馈，不增加动画依赖或外部字体。

## 家庭计划

1. 最上面填写“准备做什么”，明确必填；仍存入既有 `input.plan`。日期和时段默认值保留，放在其后按需修改。
2. 选择关键目标，主／副／复习角色保留，直接调整而不丢笔记；选择后清晰显示当前目标。
3. 选择准备使用的方法，可选，并保留快速新增入口。选择只是计划，不计实际使用次数。
4. 仅在所选目标（含明确上级方向）或所选方法存在关联时，显示经验／困难；去重并说明来源，不将未选方法的条目全部展开。
5. 近期覆盖、方法频次、历史依据、目标笔记和其他计划补充按需展开，不占据主填写路径。

正式保存计划时前后端都检查安排非空。直接记录已经发生的总结、历史读取、已成功操作回执重放不被追溯强填。
本机未完成填写仍可自动保存；既有待确认请求按原操作ID和正文重试，不擅自改写。
