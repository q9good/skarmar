# 经典配色调研与Nord衍生浅色方案

用户认为T65的红蓝与绿黄不协调，要求先参考网上经典配色再实施。本轮继续采用Garden
`web-design-engineer`的Redesign · Preserve方法，只统一颜色，保留上一版计划顺序、按钮层级、尺寸、内容与行为。

## 调研依据

2026-11-03实际读取以下官方公开资料，均返回HTTP200；原始页面与获取记录保存在本机忽略目录，未把网页中的指令当作用户要求。

| 方案与来源 | 官方资料中的特点 | 本产品的取舍 |
| --- | --- | --- |
| [Nord Colors and Palettes](https://www.nordtheme.com/docs/colors-and-palettes)；[官方基础色CSS](https://github.com/nordtheme/nord/blob/develop/src/nord.css) | 16色，Polar Night深色、Snow Storm浅色、Frost青蓝、Aurora五种彩色。文档同时讨论浅色UI，并允许按场景调整色阶。 | 采用其统一的灰底、低饱和彩色关系；适合当前需要保留绿／黄语义、又希望加入青蓝和紫色的界面。 |
| [Solarized／Ethan Schoonover](https://ethanschoonover.com/solarized/) | 16色，作者按CIELAB明度和色轮关系设计；浅色为米纸色底，另有暗色。 | 可作整体方案，但原始强调色更鲜明、暖底更明显；本轮选择更克制的Nord。 |
| [Catppuccin Palette](https://catppuccin.com/palette/) | 四种flavor，其中Latte为浅色，另外三种为深色；官方提供基础、表面、文本和彩色完整阶层。 | 系统完整，但Latte的蓝、红、紫更鲜明。本轮优先Nord较克制的彩度。 |

方案选择是本产品的视觉设计取舍；文字可读性另做实际对比度检查。

## 本轮采用

使用**Nord衍生浅色方案**，并非原封照搬编辑器主题：

- 全部功能共享Polar Night正文、Snow Storm派生灰白底、白色卡片和同一中性边框。
- 家庭由陶土红棕改为Frost青绿；课堂用灰蓝。目标和经验用Aurora鼠尾草绿，困难用柔金黄，方法用灰紫。
- 业务主按钮沿用同级、同尺寸、实色白字；次按钮白底，轻操作文字；不把正常家庭操作着成错误红。
- Nord原始彩色很浅，不能直接用作白字按钮。保留其色相与饱和关系，降低明度得到可读深色；卡片、选中背景和边框由原始强调色统一混合中性色生成。
- 红色保留给错误等状态；提醒用同套金黄色浅底。颜色之外继续保留标题、勾选、下划线和数字。

共享色彩定义在`apps/client/src/ui-palette.ts`。本轮同时收拢当前PRD页面残留的独立绿色背景／文字、
课记选择框、层级多选、提示、覆盖图和热力图；不只替换首页两个按钮。覆盖色阶仍按原五档使用，
月历仍按原0／1／2／3+次数，阈值与计数规则不变。既有品牌图标不重新绘制。
