# 2026-10-29 手机试用反馈整改

基线：`af2b4e5`，分支 `feat/tencent-informed-web`。本轮处理用户十项反馈；没有数据库迁移、依赖或环境配置变化，没有部署或访问生产业务数据。PRD同步为0.9，59条AC编号及附录D金标准保持不变。

| 反馈 | 本轮处理 |
| --- | --- |
| 1. 记录提交后及时上传 | 在线提交课记后明确显示正在上传，收到服务器回执才显示已记下；离线、上传受阻或响应未知保留原请求。修复后续flush可能加入早于本次入队的扫描、漏掉新记录直到定时器的竞态，每次请求都有前序扫描结束后的扫描机会。其他实体仍通过原有直接请求保存。 |
| 2. 今天出现未命名领域、无法退出 | 目标／方法草稿分别放在目标／方法页，目录草稿放在维护页；账号“本机未完成填写”汇总恢复。空名称显示具体类型，并禁用提交。表单增加保留草稿退出、放弃填写和二次确认，后者只清除本机输入。 |
| 3. 长期关注不易区分 | 标题与名称分开、左侧加线，各方向独立边框标签，最多显示前三项及其余数量；名称限单行避免长文字挤走两个主入口。详情和关联不变。 |
| 4. 瞬间下方出现名称错误 | 目录／目标／方法校验错误只显示在其表单里，关窗清除；不把它当成全页错误。修复空名称提交入口。 |
| 5. 切到目标仍残留 | 按草稿类型／观察所属位置展示，并清除切页的旧提示。指标和测量草稿在目标观察面板恢复，瞬间在今天／家庭记录恢复，共享需要仍从账号打开；没有删除原草稿。 |
| 6. 查看说明前置 | 全局使用说明仅留在“我的账号”的`?`按钮，保留可读无障碍名称“使用说明与手机桌面入口”；方法设置与课记不重复放置。字段自己的填写示例保留。 |
| 7. 目标／方法搜索必要性 | 搜索用于积累较多资料后定位，保留功能并收进“筛选目标”／“方法列表设置”；首屏先呈现对象，收起不清空条件。 |
| 8. 课时双口径 | 课时核对增加按老师／按课程切换，默认老师，默认上个自然月。两种口径共用正式记录及同一时间范围，按稳定ID分组，切换或换月清除旧分组明细。每条仍计一节，不从节数猜分钟；实际时长录入尚未采用。 |
| 9. 经验／困难关联分层 | 实际父子目标按层级组织，独立目标按期限分组，每个目标下有下级目标及关联方法，可跨层多选。多目标共用方法以同一ID同步勾选，不自动选择父子或关联目标。长列表可查找，历史未关联现有目标的方法仍可选择。 |
| 10. 新建入口范围 | “新建经验／新建困难”仅在“经验库与困难”分段出现；“要处理的”集中处理已有事项。详情里的编辑／派生入口保留。 |

## 根因和保留规则

此前基础草稿及错误直接渲染在整个工作区；观察组件即使隐藏模式也渲染恢复入口和提示，导致目录错误出现在瞬间按钮下、草稿跨页残留。现在按所属位置展示，未提交数据仍保留，不能用清空浏览器存储掩盖问题。

课记队列继续采用原账号／空间核对、稳定目录依赖、持久化原请求、幂等操作ID和服务器事务。新flush串行等待前序扫描，每次提交对应一次后续扫描；不会通过改操作ID重发来避免等待，也不会在回执前把本机队列计入正式课时。结果未知时不提供直接丢弃入口。

关联选择只修改明确勾选的ID。层级和同一方法多处展示不额外生成关联、目标、实践次数或经验有效性。课时按课程汇总也不改变机构／家庭的统计区分，不新增金额计算。
