# skarmar 长期方向、方法与目录种子内容草案

日期：2026-10-28。状态：**课程／老师名称已确认并保存清单；长期方向与方法仍为讨论稿。尚未导入或实现模板选择功能**。

本稿响应“准备种子数据，重点讨论长期目标及对应方法，也作为新录入的提示词”。
依据为用户此前的家庭实践说明、[PRD 0.6](prd-family-intervention.md)和本轮直接核对的三份公开参考页。
孩子的年龄、沟通方式、具体起点与当前重点仍待家庭补充。课程／老师实际名称已由家庭提供，见§5。
下列例子均为编写的候选内容，不是孩子已经发生的表现，也不是已验证有效的家庭经验。

## 1. 内容怎样进入产品

建议把同一份内容同时用于两个入口：

- **参考库**：完整保留候选方向与做法，新建时按需查看；查看不创建业务记录。
- **确认后的种子记录**：家庭明确选择并修改后，才创建自己的目标、方法和适用关系。

不把整套参考库自动变成“正在推进”的目标和“正在使用”的方法。首次可先选少量实际重点，
具体数量由家庭决定，不要求同时开展六个方向。没有选中的参考仍可用于今后录入。

种子内容不包含已完成训练、上课记录、经验有效次数、困难、反馈、基线测量或达标结果。
公开资料不能代替家庭确认；不把候选方法标成“老师已指导”或“多次观察到有帮助”。

## 2. 长期方向候选

以下六个是便于家庭管理的产品组织方式，不是诊断维度、标准量表或完整治疗方案。
G 编号仅用于本稿核对关系，最终界面不要求家人记住编号。
长期目标记录方向；中短期目标承接当下可练习的本领，二者可独立也可明确关联。

| 编号与建议名称 | 生活意义 | 可以留意的变化 | 对应方法候选 |
| --- | --- | --- | --- |
| G01 和人分享关注与乐趣 | 不只有“想拿到东西”，也愿意与家人分享有趣的事，让人与活动之间出现更多联结 | 主动展示、指给人看、邀请加入、回应家人分享；不以持续对视为要求 | M01、M02、M03 |
| G02 主动表达需要与想法 | 能表达想要、不要、帮助、休息及自己的看法，减少因表达不清带来的困难 | 在真实需要时主动用目前能用的语言、手势或其他沟通方式表达；能否少一点提示 | M02、M05、M06、M08 |
| G03 参与共同活动并接续互动 | 更容易一起玩、学习和做事，逐步接上他人的行动与想法 | 在合适支持下轮流、回应、持续参与，走开后能否重新接上；记录活动与成人帮助 | M01、M03、M04、M05、M08 |
| G04 愿意尝试与主动探索 | 以温和的成功体验打破不敢尝试的循环，逐渐愿意了解新事物 | 主动开始、接受一个小变化、求助后再试，或提出自己的新玩法；不以接受所有要求为目标 | M01、M04、M06、M07 |
| G05 遇到困难时能求助、调节与适应 | 需要帮助时有办法表达与获得支持，变化或受挫后逐渐找回参与的可能 | 提前表达不适、使用已会的求助／休息方式、在成人支持下恢复；能否再试与当时条件一起看 | M04、M05、M06 |
| G06 日常生活逐渐自主 | 在吃饭、清洁、穿衣、整理等生活中，能自己选择和完成更多事情 | 哪些步骤独立、哪些需要提醒或示范；换人或地点后是否仍能用上 | M05、M07、M08 |

“共同参与时的注意”放在 G03；如果孩子在非互动任务中另有明确的注意困难，
可另设中短期目标或调整方向，不把所有注意问题等同于社交困难。
“学习效率”过于宽泛，建议落实为具体活动中能否理解、开始、接续及减少帮助。
“在不同场合也会”是每个适用目标都可观察的维度，不另增一套泛化目录。

### 每个方向怎样承接近期本领

以下只说明层级写法，不预置难度、成功比例或完成日期：

| 长期方向 | 可讨论的近期本领示例 | 标准怎样个体化 |
| --- | --- | --- |
| G01 | 看到有趣的东西时，主动让家人也注意到 | 写清自然机会、孩子的表达方式及成人是否先提示 |
| G02 | 玩具需要帮助时，用当前会的方式求助 | 区分主动、提醒后表达和示范后表达，不限定必须说话 |
| G03 | 和家人轮流完成一个熟悉游戏 | 先观察当前能接续的轮次及帮助，再定适合的下一步 |
| G04 | 熟悉游戏中愿意尝试一种小变化 | 写清改变了什么及成人怎样支持，不把新奇越多当作越好 |
| G05 | 卡住时表达求助或休息 | 先保证表达会被回应，再看是否能在支持下返回；不要求当次必须返回 |
| G06 | 洗手时逐渐独立完成一个目前需帮助的步骤 | 分清原本会的步骤与本次练习的步骤，记录帮助变化 |

长期方向可以只写观察迹象。近期标准建议选一个主要变化，不同时强制填写成功率、时长、
提示次数及迁移情况。条件不同时保留说明，不硬拼百分比；没有基线就留待观察。

## 3. 方法候选：写成人实际怎样做

以下是可修改的做法样例，借鉴自然情境支持、示范、提示、视觉支持和任务分析等实践思路。
这些中文名称及组合步骤不是某个研究方案的原样复现；是否适合孩子及实施细节需要结合家庭和专业建议。
方法可关联多个目标；关联不代表每次实际使用，更不代表已经有效。

### M01 跟随兴趣，再加入一点互动

- **做法**：观察孩子正在关注的内容，先模仿或加入已有玩法；回应其动作或表达，提供一个容易接上的互动邀请，再根据反应调整。
- **观察意图**：孩子是否更愿意让家人加入、发起或回应互动；成人改变了什么。
- **适用条件**：孩子愿意参与、成人能跟随其兴趣的游戏与日常活动。
- **候选目标**：G01、G03、G04。
- **空框短例子**：`例如：先加入他的玩法`

### M02 留出表达机会，及时自然回应

- **做法**：在孩子已有表达需要的日常机会中，留出适合其节奏的回应空间；必要时示范当前能用的表达方式，表达后及时回应，结果尽量与活动本身相关。
- **观察意图**：主动表达与提示后表达有何不同，表达是否更丰富；分享与请求分开记录。
- **适用条件**：孩子确实有沟通意图、成人能理解并回应的情境。不以口语为唯一条件，不因等待表达而拖延基本需要或孩子已明确表达的拒绝。
- **候选目标**：G01、G02。
- **空框短例子**：`例如：求助后一起继续玩`

### M03 用轮流接续共同活动

- **做法**：从孩子熟悉且喜欢的活动开始，成人用清晰的动作、语言或标记示范轮流；接续到孩子的一轮时按需帮助，随参与情况逐步调整轮次与复杂度。
- **观察意图**：能否接上、主动邀请继续、需要何种帮助；不只记录成人要求下完成几次。
- **适用条件**：可自然轮流的滚球、搭建、翻书等；成人也跟随孩子的发起。
- **候选目标**：G01、G03。
- **空框短例子**：`例如：你一块我一块搭积木`

### M04 在熟悉活动中只增加一个小变化

- **做法**：从已能参与的活动开始，只调整一个材料、步骤或规则；提供示范与求助机会，回应合理尝试，再按实际反应保持、降低或调整难度。
- **观察意图**：是否愿意开始、尝试、提出变化或在求助后继续；记录改变了哪个条件。
- **适用条件**：孩子对原活动有兴趣，并有能力在支持下接触这个变化。明显持续难受时先调整支持或要求，不把坚持完成当作成功标准。
- **候选目标**：G03、G04、G05。
- **空框短例子**：`例如：熟悉玩法只换一种材料`

### M05 提前说明变化，提供真实选择

- **做法**：用孩子能理解的语言、实物或图片说明接下来做什么；在可行范围内提供真实选择，对结束、转换或变化按需预告，并确认孩子是否理解。
- **观察意图**：是否更清楚接下来发生什么，能否表达选择、疑问或不同意，转换时需要多少支持。
- **适用条件**：活动转换、生活步骤和可选择的安排；提示材料须是孩子理解的，不把成人展示过等同孩子理解了。
- **候选目标**：G02、G03、G05、G06。
- **空框短例子**：`例如：先说明接下来做什么`

### M06 接住困难，示范求助与恢复

- **做法**：观察可能的不适与卡住之处，降低语言或任务负担；示范孩子能使用的求助、休息或拒绝表达并回应。状态合适时邀请其选择返回、换一种做法或结束。
- **观察意图**：能否更早表达、得到帮助、逐渐恢复；是否愿意再尝试，保留未返回的实际情况。
- **适用条件**：孩子有困难或不适时，先理解当时需要；不能只凭表面行为判断其原因。
- **候选目标**：G02、G04、G05。
- **空框短例子**：`例如：卡住先示范怎样求助`

### M07 拆成小步骤，示范后逐渐少帮

- **做法**：把任务拆成可理解的步骤，保留孩子已有能力；选择当前可学的一步，提供足够而不过度的示范或提示，观察是否可以逐步减少帮助。
- **观察意图**：哪个步骤独立、哪个需要哪种帮助；变化是来自技能、帮助还是任务难度调整。
- **适用条件**：日常自理或可拆分的操作任务，不用一套固定提示顺序套所有任务。
- **候选目标**：G04、G06。
- **空框短例子**：`例如：只示范还不会的一步`

### M08 换一个条件，观察能否用上

- **做法**：熟悉条件下出现稳定表现后，选择更换一位家人、一种材料或一个地点中的一项；保留必要支持，观察能否用上；不顺利时再调整，避免同时改变所有条件。
- **观察意图**：原有能力能否迁移，需要哪些帮助；不能把不同条件下的结果直接当作退步。
- **适用条件**：已经有可参考表现、希望用于真实生活的目标；不因某次成功就认定掌握。
- **候选目标**：G02、G03、G06；其他方向按具体内容再关联，不自动绑定全部。
- **空框短例子**：`例如：换一位家人试同一件事`

### 家庭已有“因果论”怎样放

保留用户已说明的意图，建议名称写成**“理解选择的自然结果”**，作为另一个待讨论的家庭方法，
不把它混进所有种子方法或贴成独立循证疗法。
可以记录成人怎样提前说明、结果是否能即时理解、孩子如何参与处理及是否理解了联系。
例如选择把玩具放在某处，下一次一起从那里找到；或水洒出后按能力一起擦干。
这只是写法例子，不表示具体情境必然适合孩子，也不额外施罚或撤去基本需要。
待家庭提供实际做法后再确定步骤和目标关联。

## 4. 同时作为新录入提示

复用内容，不新增给家人填写的必填问题。当前集中字段文案见
[field-guidance.ts](../apps/client/src/field-guidance.ts)，已有三种观察模板和按需展开的例子。
**按长期方向切换示例、选择整份参考填入草稿，均是拟议改进，当前未实现。**

| 使用处 | 空框短提示候选 | 点“例子”后可展开的引导 |
| --- | --- | --- |
| 目标名称 | 例如：主动表达需要 | 想帮助孩子在什么生活情境中做到什么？先写一种具体能力。 |
| 生活意义 | 例如：需要帮助时能说明 | 这会让学习、交往或日常生活哪里更顺？可以保留好奇、信心等愿望。 |
| 观察标准／次数 | 例如：求助需要几次提醒 | 在哪些真实机会中，孩子会主动表达、提醒后表达或需示范？没有起点时先观察。 |
| 观察标准／时长 | 例如：一起玩时能接续多久 | 什么活动、什么支持下参与了多久？长短不是唯一价值，条件改变要说明。 |
| 观察标准／步骤 | 例如：哪一步还需示范 | 哪些步骤独立，哪些需要什么帮助？先挑一个当下想改变的地方。 |
| 帮助条件 | 例如：需要时给一次示范 | 当时成人做了什么，材料、任务或环境是否改变？ |
| 方法做法 | 例如：先加入他的玩法 | 成人先做什么，孩子可能怎样回应，成人再怎样调整？写能照着做的动作。 |
| 总结／实际表现 | 例如：主动求助后继续玩 | 实际发生了什么，哪里主动、哪里需要支持？没有做到或无法判断也如实留存。 |
| 新经验 | 例如：先跟随后更愿意互动 | 哪个具体做法在什么条件下可能有帮助？这是想法还是已有观察，由家人选择。 |
| 新困难 | 例如：换材料后不愿继续 | 原来希望怎样，实际怎样，成人怎样回应？把现象和原因猜测分开。 |
| 老人补充课堂观察 | 例如：今天哪处更顺或更难 | 老师怎样支持？孩子有没有主动发起、求助、尝试或把本领用到新情境？哪一点值得带回家试？ |

上表是对现有字段的候选引导，不新增表单块。老人仍可只记课程和老师，或选择一个最值得记的观察；
不要求其回答整套问题，更不要求其判断行为功能或疗效。

示例与正式内容的边界：

- **只看提示**：placeholder／展开例子不进入 value，聚焦、切模板、提交空框都不会保存例子。
- **选择参考来新建**：明确点选后预览哪些字段将进入本机草稿；允许删改，正式保存才创建记录。
- **已经输入内容**：切参考不覆盖文字；需要替换时由人逐字段确认或取消，不悄悄追加。
- **缺少实际结果**：任何示例都不自动填入测量、总结、经验有效依据或困难解决情况。

## 6. 确认后实施的边界

1. 确认要保留的长期方向、个体化名称与观察重点，以及已在用／准备试用的方法。
2. 列出确定创建的目标、方法、课程和老师及明确关联，提供可删改的预览；参考库保留未选内容。
3. 采用现有共享写入、版本与权限规则。导入重试不得重复造记录；与现有相似名称不自动合并，已有编辑不被初始化覆盖。具体批量入口与幂等方式待实现时核定。
4. 不跟随每次部署自动补种或清库，不重设空间、账号或管理员。提醒沿用已确认的应用规则，预览中说明会产生的安排，不批量伪造逾期任务。
5. 对种子关系、重复操作、保留编辑、提示不入库与目录选择做合成库验证。实际写入哪个环境、何时发布，按后续用户指令执行。

当前仅保存讨论稿；没有修改 PRD 定案、应用代码、数据库或线上配置，没有读取生产账号和业务数据。

## 7. 本轮公开参考及适用范围

2026-10-28 直接通过公开网页读取，三页均 HTTP 200。没有重新进行系统综述、完成专业模块培训，
也没有把公开类别的证据等级赋给上述自编名称、组合步骤或软件本身。

- [NICE CG170 Recommendations §1.3.1](https://www.nice.org.uk/guidance/cg170/chapter/recommendations)：直接核对正文。建议考虑结合游戏、家长／照护者／教师参与的社会沟通干预，促进共同注意、参与和相互沟通；按发展水平调整，提高成人理解与回应；该干预应由受训专业人员实施，学龄前可考虑家长等中介。用于支持G01–G03及成人支持视角，不据此认定任意家庭玩法等同该干预。
- [WHO Caregiver Skills Training](https://www.who.int/teams/mental-health-and-substance-use/treatment-care/who-caregivers-skills-training-for-families-of-children-with-developmental-delays-and-disorders)：直接核对项目页。内容覆盖沟通、参与、日常生活技能、困难行为与照护者应对，并使用日常活动机会。页面所列培训包面向2–9岁有发育迟缓／障碍儿童家庭；当前孩子年龄未知，不能据此断定全部内容直接适用。
- [UNC AFIRM Modules](https://afirm.fpg.unc.edu/afirm-modules/)：直接核对公开目录，列有Naturalistic Interventions、Parent-Implemented Intervention、Prompting、Task Analysis、Visual Supports等。只用来核实实践类别存在，未据目录判断孩子适合哪一模块、应采用何种剂量或会达到何种效果。
